## 0. 路线图（动手前）

### 0.1 诊断（来自 P4a/b，非新假设）

1. **H5 oracle：天花板是表征级**：SSL 特征同试件内线性 ~0.68，跨试件 0.60；+20% test 标签都无效 → 缺陷存在与试件分布强耦合。

3. **未试过的杠杆**：改造 SSL 任务本身（而非掩码模式/微调头/融合）。

### 0.2 假设与失败判据

| 假设 | 方法 | 预期 | 失败判据 |

## 1. 方法

### 1.1 注入模型（物理保真）

- 输入：clean A-scan (49, 512) — 原始数据，**未归一化**（注入在归一化前，amp_range 是 raw 值）
- 注入位置：随机 (b0 ∈ [8, 41], t0 ∈ [20, 492])，避开边沿
- 缺陷形态：2D 高斯峰
  ```
  defect[b, t] = A * exp(-(b-b0)²/(2σ_b²)) * exp(-(t-t0)²/(2σ_t²))
  A ∈ Uniform(800, 3000)   # raw 振幅（基于实测 pos 相对 neg 峰值差异 200-3700）
  σ_b ∈ Uniform(0.8, 2.0)  # 1-4 beam 空间范围
  σ_t ∈ Uniform(2.0, 6.0)  # 4-12 time 深度范围
  ```
- 注入验证（冒烟测试）：注入后局部峰值 q25/50/75 = 5725/6597/7753，**与真实 pos 局部峰值 5399/6447/7640 高度匹配**（SNR 23-258，缺陷可见但非压倒性）。

### 1.2 编码器架构（修改自 P1 MAEEncoder）

- 复用 P1 三层 Conv+MaxPool (32→64→128 ch)，输出 (B, 128, 6, 64)
- 新增 `spatial_pool = AdaptiveAvgPool((7, 16))` → 空间特征保留用于定位头
- `global_pool = AdaptiveAvgPool((1, 1))` → 全局特征用于二分类
- proj Linear(128→128) → d_model

### 1.3 多任务损失

```
L = 0.1 * L_recon (MAE smooth_l1)    # 保持本底知识
  + 1.0 * L_inj   (BCE)             # 注入检测 (H6 核心)
  + 1.0 * L_loc   (BCE, 7×16 热图)   # 注入定位 (辅助)
```

## 4. 诚实分析

### 4.1 注入任务学到了什么？为何不迁移？

**P5 注入任务成功学到**：编码器能高准确率区分"clean A-scan"和"clean A-scan + 高斯峰"。**学到的是"高斯峰形态"**——一个与真实缺陷形态**有差距**的特征：
- 真实 PAUT 缺陷回波：含特定频率成分（依赖缺陷类型）、非对称包络、ringdown 振荡、TCG 补偿后的振幅差异。
- 注入的合成缺陷：对称 2D 高斯，固定形态，无频率结构，无 ringdown。

→ **编码器学到了"高斯峰检测器"，但真实缺陷的形态空间与高斯峰形态空间不重合**。这是合成数据失效的典型模式：**模型学到了合成特征，而非真实物理**。

### 4.2 与 P4a/b 失败模式的对比

| 阶段 | 训练目标 | 学到的特征 | 跨试件迁移性 |
|---|---|---|---|
| P1 SSL | MAE 重建被掩码波束 | "试件本底统计" | 中（0.579） |
| P4b SSL | MAE 重建被掩码深度块 | "深度方向平滑统计" | 更差（0.513） |
| **P5 SSL** | MAE + 注入检测 + 注入定位 | **"高斯峰检测器"**（合成特征） | **最差（0.527）** |

→ **改造 SSL 任务本身也未能突破**。而且**改得越多，跨试件泛化越差**——因为合成任务与真实任务的特征空间不重合，强行让编码器聚焦合成特征反而挤占了其学习真实（本底/缺陷）特征的能力。

### 4.3 物理注入不够物理

P4b 报告 §5 明确指出："**仅当能生成与真实 .nde 几何（offset 80–85mm、71° focal law、TCG 增益、实际缺陷回波响应）一致的合成缺陷，才可能教'缺陷回波物理'**。" 本阶段的"物理保真"是**简化版**：
- 缺：TCG（time-corrected gain）补偿
- 缺：探头脉冲响应（Gaussian 包络+正弦载波，但实际 PAUT 数据是 **整流包络**int16，不是 RF）
- 缺：实际 focal law 与声束偏转
- 缺：不同缺陷类型的回波特征（porosity / lack of fusion / cracks 形态差异大）

→ **简化版合成数据**的训练结果证明：**没有 CIVA / 真实射线模型仿真，无法让合成数据特征空间与真实缺陷特征空间重合**。这是资源型瓶颈，不是算法/模型能解决的。

### 4.4 H5 oracle 的关键扩展

P4a H5 oracle："+20% test 标签都无效 → 瓶颈是表征级"。
**P5 扩展**："+100% 物理保真合成标签也无效 → 表征级的瓶颈是'真实缺陷形态'本身的跨试件变异，不是标签量、不是合成可行性"。

更精确地说：
- H5 oracle 验证的是"加同分布标签无效"（同分布 = 同一试件）
- P5 验证的是"加跨试件恒定的合成标签无效"（跨试件恒定 = 注入过程对所有试件相同）
- 唯一剩下的杠杆：**改变试件分布本身**（新试件数据 / CIVA 级合成）——但这超出本机算力范围。

---

## 5. 结论

**P5 为明确负面结果**，与 P4a/b 共同完成 PAUT 跨试件缺陷检测的天花板定位图景：

1. **改造 SSL 任务本身（缺陷注入）→ 学到合成高斯峰特征，但与真实缺陷形态不重合**。比 P1 baseline 更差（0.527 vs 0.579）。
2. **H5 oracle 关键扩展**：物理保真的合成标签也无效 → 真正的瓶颈是"真实缺陷形态空间"在 5 试件间的强变异（每试件不同 TCG/focal law/缺陷率）。
3. **P0–P5 完整证据链**：所有廉价杠杆（增强/微调/TTA/融合/形态头/改掩码/改任务）均未稳健破 0.60。
4. **唯一未证的翻盘点**：资源型——新试件数据或 CIVA 级合成（需要设备/合作方数据/物理仿真工具链，超出本机算力）。

**可发表方法学贡献（即使无算法突破）**：
- PAUT 5 试件数据集的"缺陷-试件强耦合"问题完整证伪图（P0–P5 全部技术）
- SSL "合成注入"路线的可学但不可迁移证据（与 H5 oracle 互证）
- 多 seed 验证方法学（P2 LoRA 单折乐观 → P4a 多 seed → P5 三 seed 一致负面）
- 资源型归因：5 试件/1798 位置/0.5%–76% 缺陷率耦合下，位置级 LOOCV 的 ~0.58（pooled 0.62）是稳定表征上限
