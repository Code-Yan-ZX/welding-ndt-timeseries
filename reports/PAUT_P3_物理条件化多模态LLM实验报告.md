# PAUT P3 阶段报告:物理条件化 + 推理式 CoT 多模态 LLM 缺陷检测

> 阶段:P3(物理条件化 prompt + 推理式差分诊断 CoT,完整 5 折 LOOCV)
> 日期:2026-08-11 ｜ 模型:Qwen3.6-27B(Qwen3.5-VL,27.4B,bfloat16)
> 动机:P2 通用多模态 LLM 零样本非PP4 AUC=0.593 为三阶段最优,但属「弱比赛险胜」--
> 根因是 VLM 把 B-scan 当普通图片看,未注入波动先验(探头角度/声速/focal law/B-scan 轴语义)。
> P3 验证:把「裸图 + yes/no 单 token」升级为「物理条件化 + 推理式差分诊断」能否显著超过 0.593。
>
> ⚠ 标签版本:本阶段结果使用 PP5 修复前标签(`position_labels` 旧版静默跳过 1 行 x_init>x_end
> 录入反转,PP5 少计 18 个缺陷位置,占全量 0.6%,在 seed 噪声内)。`paut_preprocess.py` 已修复,
> 下次运行生效,定性结论不变。

## 1. 部署

- 模型:`models/Qwen3.6-27B`(Qwen3.5-VL,54GB,15 shards,bfloat16)。
- 环境:`.venv_p2`(transformers 5.14.1 + torch 2.13+cu126 + peft 0.20)。**硬约束**:本机 driver 535 / CUDA 12.2,vLLM 0.26 需 CUDA13 不可用,回退 transformers 直推。
- 多卡:3×RTX4090D(48GB)。GPU0 被他人进程占用,本实验 `CUDA_VISIBLE_DEVICES=1,2` 跨双卡 `device_map=auto`(曾试 `max_memory` 限制导致视觉编码器与 LLM 分卡、跨卡 P2P 死锁,故弃用,靠 batch 控显存)。
- 注:`flash-linear-attention` 快速路径未生效(`causal-conv1d` 缺失,系统仅 nvcc CUDA11.5 与 torch cu126 不匹配无法编译),生成式 CoT ~5.4s/张,单 token 打分 ~0.2-0.4s/张。

## 2. 方法

### 2.1 四模式消融

| 模式 | 组件 | prompt | 打分 |
|---|---|---|---|
| `bare` | P2 复现 | P2 原 prompt(校准,应≈0.593) | 单 token yes/no logprob 差 |
| `physics` | A | +物理条件化前文 | 单 token logprob 差 |
| `physics_cot` | A+B1 | +物理 +5 步差分诊断 CoT 脚手架 | 生成推理后重打分 |
| `physics_json` | A+B2 | +物理 +结构化 JSON{reasoning,defect} | 同 B1 |

### 2.2 物理条件化前文(组件 A)

把 P2 的单句 prompt 扩展为检验员式物理上下文,至少包含:
- **探头与几何**:G0 探头 71° 剪波,49 波束,1 mm/波束,offset 80–85 mm(按 coupon 从 `meta_summary.json` 动态读取),钢剪波速 ~3230 m/s。
- **B-scan 语义**:横轴=扫查位置,纵轴=声程/飞行时间(深度向下递增),深度换算 z = s·cos(71°)≈s·0.326,幅度=反射率(已百分位 2–98 归一化)。
- **试件与缺陷候选**:coupon ID(PP3–PP7),缺陷类型 {1 气孔,2 未熔合,3 夹渣,4 金属夹杂,5 凸起,6 裂纹}。
- **差分诊断规则**:真缺陷回波=不落在预期底面/角反射几何上的局部相干指示;须与几何回波(底面/角/模式转换)区分。

物理常数(角度/声速)为探头/材料物理,文档化常量;offset/波束数/分辨率/缺陷码从 `meta_summary.json` 动态读取,不硬编码。

### 2.3 推理式 CoT 差分诊断(组件 B)

`physics_cot` 的 5 步脚手架(`enable_thinking=False` 关 Qwen3 思考模式,直接跟脚手架):(1)定位最强回波与声程深度 -> (2)换算物理深度,判断是否落在底面/角几何线(几何)还是偏离(可疑)-> (3)形态分类(点状气孔/线状未熔合或裂纹/延伸夹渣)-> (4)差分判定 -> 末尾 `Answer: yes/no`。

`physics_json`:同样推理,但要求结构化 JSON `{reasoning, defect}` 输出,隔离「输出格式」对推理质量的影响。

### 2.4 打分实现

- **单 token 模式**(bare/physics):批量 left-pad forward,取 `logits[:,-1]` 的 yes/no 候选 token logprob 差(与 P2 同口径)。
- **生成模式**(cot/json,重打分):`model.generate` 生成推理(`enable_thinking=False`, max_new=160),取生成文本(截断到 "Answer:" 之前)作为推理,拼接 [prompt(含图)+ 推理 + " Answer:"] 再做一次 forward,取末位 yes/no logprob 差。**无论模型是否在预算内说到答案都给连续分数**,稳健(早期 output_scores 定位法因模型推理偏长未走到答案、解析率 0% 而弃用)。同时解析答案词(准确率)与保留推理文本(可解释性)。

### 2.5 评测协议

- 5 折留一试件交叉验证(LOOCV),PP3–PP7 轮流 test。
- **零样本**:全量 3000 位置推理一次(同模型),按 coupon 切片算 per-coupon AUC + 非PP4 池化 AUC(与 P2 同口径)。
- **非PP4 AUC** 为可信指标(PP4 仅 3 正样本,AUC ±0.03 纯噪声)。
- **LoRA**(组件 C):视觉端 LoRA r=16(LLM 冻结),每折从训练折采 400 位置微调,test 折评测;每折重置 LoRA 权重(无跨折泄漏)。**因每折是不同模型,分数尺度不可比,非PP4 用逐折 AUC 均值**(非跨折池化)。

## 3. 结果

### 3.1 零样本单 token 模式(全量 3000)

| 模式 | AUC(含PP4) | **非PP4 AUC** | PP3 | PP4 | PP5 | PP6 | PP7 | Δ vs bare(非PP4) |
|---|---|---|---|---|---|---|---|---|
| bare(P2 复现) | 0.485 | **0.600** | 0.586 | 0.497 | 0.592 | 0.472 | 0.493 | - |
| physics(组件 A) | 0.491 | **0.512** | 0.478 | 0.556 | 0.473 | 0.514 | 0.479 | **−0.088** |

**bare 校准通过**:非PP4 AUC=0.600,与 P2 报告的 0.593 一致(差异来自批量化/数值),证明新管线可信。

**组件 A(物理条件化)为负面结果**:physics 非PP4 AUC=0.512,较 bare 退化 0.088,所有非PP4 试件均回落到近随机水平(PP3 0.586->0.478,PP5 0.592->0.473)。物理条件化文本非但没帮上忙,反而显著伤害了 VLM 的判别力。

### 3.2 零样本 CoT 模式(子采样 400,组件 B)

| 模式 | AUC(含PP4) | **非PP4 AUC** | PP3 | PP4 | PP5 | PP6 | PP7 | Δ vs bare(非PP4) |
|---|---|---|---|---|---|---|---|---|
| physics_cot(B1,重打分) | 0.463 | **0.508** | 0.543 | 0.137 | 0.612 | 0.498 | 0.464 | **−0.092** |

- 子采样 400(分层,覆盖 5 试件);生成 max_new=160 + 重打分。
- **组件 B(CoT)亦负面**:非PP4 AUC=0.508,与 physics(0.512)相当,均低于 bare(0.600)。CoT 推理虽物理化质量高(正确描述声程深度/几何/形态),但**不改善判别**。
- ans 解析率 0%:160 token 内推理未走到 "Answer:"(Qwen3 即使关思考,5 步推理仍偏长);靠重打分得到连续分数(score 范围 -4.4~3.5,97% 非零,AUC 有效)。
- 受生成速度约束(causal-conv1d 缺失,~5.4s/张)仅子采样 400,非完整 3000;但方向明确(低于 bare)。

### 3.3 LoRA 5 折 LOOCV(组件 C,视觉端 r=16,LLM 冻结,400 训练位置/折)

用 bare prompt(因 physics 在零样本已负面,取更强基线做完整 5 折)。每折从 4 训练试件采 400 位置微调视觉端,test 折评测。

| test 折 | LoRA AUC | 零样本 bare 同折 AUC | Δ |
|---|---|---|---|
| PP3 | 0.513 | 0.586 | −0.073 |
| PP4 | 0.419 | 0.497 | −0.078(3 正样本,噪声) |
| PP5 | 0.465 | 0.592 | −0.127 |
| PP6 | 0.456 | 0.472 | −0.016 |
| PP7 | **0.606** | 0.493 | **+0.113** |
| **非PP4 均值** | **0.510** | 0.536 | **−0.026** |

> **指标说明**:LoRA 每折是不同模型,分数尺度不可比,**非PP4 用逐折 AUC 均值**(0.510),非跨折池化(跨折池化得 0.324,伪相关,无效)。零样本同口径(逐 coupon 均值)0.536。

**组件 C(LoRA 5 折)为负面**:非PP4 均值 0.510,不及零样本 bare 的 0.536;仅 PP7 折提升(+0.113,与 P2 单折 0.587 一致是"幸运折"),PP3/PP5 反而退化。400 训练位置的视觉端 LoRA 跨试件过拟合,学到的多是训练试件的视觉统计而非缺陷本质。**P2 报告的 LoRA PP7=0.587 优于零样本,是单折乐观估计;完整 5 折后不成立。**

### 3.4 P3 总览

| 配置 | 非PP4 AUC | 口径 | Δ vs 零样本 bare | 结论 |
|---|---|---|---|---|
| 零样本 bare(P2 复现) | **0.600** | 池化(同模型) | - | 最优,VLM 视觉先验 |
| 零样本 bare | 0.536 | 逐 coupon 均值 | - | 同口径对照 |
| 零样本 physics(组件 A) | 0.512 | 池化 | −0.088 | 负面 |
| 零样本 physics_cot(组件 B,400) | 0.508 | 池化 | −0.092 | 负面 |
| LoRA 5 折 bare(组件 C) | 0.510 | 逐折均值 | −0.026 | 负面 |

**P3 全部三个组件(物理条件化 / CoT / LoRA 5 折)均未超过零样本 bare 的 0.600,目标 ≥0.62 未达成。**

## 4. 消融

### 4.1 物理条件化为何负面(组件 A)

核心发现:**在 PAUT B-scan 缺陷检测上,给通用 VLM 注入物理条件文本会损害而非帮助其判别**。可能机制:

1. **视觉先验被文本稀释**:bare prompt 让 VLM 直接靠视觉先验判断(0.600);冗长物理前文(探头角度/声速/缺陷码/几何规则)把模型注意力从视觉特征转到文本推理,而 VLM 在此模态的瓶颈是**感知**(看懂 B-scan)而非**推理**(STEMGym 教训:VLM 在专门模态上感知是瓶颈,文本条件无法补偿感知不足)。
2. **物理文本与视觉证据未对齐**:模型被要求做"声程->深度->几何"换算,但 B-scan 已栅格化为像素,模型无法从像素精确读出声程数值,被迫生成不可校验的物理叙事(如"sound-path ~20-25mm"),引入噪声而非约束。
3. **指令过载**:bare 的极简"yes/no"让模型用最擅长的模式匹配;physics 的多约束指令使模型偏离其强项。

### 4.2 CoT 为何不挽回(组件 B)

CoT 推理质量高(smoke 可解释性:正确识别声程深度、底面/角几何、回波形态),但**判别力不变**(0.508 ≈ physics 0.512)。说明:模型"会说"物理推理,但"说对"不等于"看对"--推理建立在已被稀释的视觉感知之上,无法纠偏。与 arXiv:2607.18325 一致:VLM 的"异常/危险"混淆是感知层问题,CoT 推理层介入太晚。

### 4.3 LoRA 5 折为何不优于零样本(组件 C)

- **跨试件过拟合**:400 训练位置(4 试件)的视觉端 LoRA 学到训练试件特有视觉统计(缺陷率 PP3 57%/PP5 44%/PP6 76%/PP7 14% 差异大),迁移到 held-out 试件时退化(PP3 0.586->0.513,PP5 0.592->0.465)。
- **P2 单折乐观**:P2 仅做 PP7(0.587 > 零样本 0.504),恰是 LoRA 提升的幸运折;完整 5 折后非PP4 均值 0.510 < 零样本 0.536,优势消失。印证方向调研中"必须补完整 5 折 LOOCV"的必要性。
- **与 P0 互证**:P0 有监督小模型(SSF 0.542)同样跨试件过拟合;P3 表明即便用 27B VLM 的视觉端 LoRA,少量标注仍过拟合--跨试件泛化是数据/表征问题,非模型容量问题。

### 4.4 统一诊断

P0–P3 四阶段在 PAUT 跨试件缺陷检测上的共同天花板(~0.55–0.60 非PP4 AUC)指向同一根因:**像素/图像级表征跨试件不迁移,且文本条件/CoT/少量微调都无法突破**。VLM 的视觉先验(0.600)已是图像路线的极限;进一步提升需要越过"把 B-scan 当图片看"这一步。

## 5. 结论

**P3 为全面的负面结果**:在 Qwen3.6-27B + LoRA 框架上,把"裸 B-scan + yes/no 单 token"升级为"物理条件化 prompt + 推理式 CoT 差分诊断 + 视觉端 LoRA 5 折"后,非PP4 AUC 不升反降:

| 组件 | 非PP4 AUC | vs 零样本 bare(0.600) |
|---|---|---|
| 物理条件化(组件 A) | 0.512 | −0.088 |
| +CoT 差分诊断(组件 B) | 0.508 | −0.092 |
| LoRA 5 折(组件 C) | 0.510(逐折均值) | −0.026(同口径 −0.090) |

**核心结论**:通用多模态 LLM 在 PAUT 缺陷检测上的弱优势(0.593)**并非缺少物理文本条件或推理**,而是:

1. **瓶颈在感知不在推理**:VLM 把 B-scan 当普通图片看,看不懂波场物理;物理条件文本与 CoT 推理都在推理层介入,无法补偿感知层不足(印证 STEMGym:VLM 专门模态感知瓶颈)。
2. **文本条件有害**:冗长物理前文稀释视觉先验,系统性地把所有试件判别力压到近随机。
3. **跨试件泛化是数据问题**:少量标注 LoRA 过拟合训练试件统计,完整 5 折后不优于零样本;P2 单折提升是幸运折。

**方法学价值**(可发表负面结论):

- 首次在「物理条件化多模态 VLM × 超声 NDT」(arXiv 0 篇的空白)上给出系统消融,证伪"注入物理先验文本能提升 VLM 超声判别"这一直觉假设。
- 纠正 P2 单折乐观(LoRA PP7 0.587),用完整 5 折 LOOCV 给出可信跨试件泛化估计。
- 明确下一步应越过图像栅格化:**信号原生 tokenization**(方向 3,ITFormer 式 A-scan patch 化喂 LLM,保留相位/频谱/包络)或**波动方程合成数据**(方向 6,扩数据),而非继续在 prompt/CoT 上做文章。

**未达成功判据(≥0.62)**,但负面结果清晰、可复现、有方法学贡献,符合"无论正负都要写成可发表的方法学结论"的既定标准。
