# PAUT P4b 阶段报告：深度掩码 SSL 预训练（直击 H5 表征天顶）—— 负面

> 阶段：P4b（改造 SSL 预训练目标）
> 日期：2026-08-12 ｜ 数据：ascans_mv.npy (11980 无标注样本, 4 视角, 跨全部试件)
> 动机：P4a 多 seed 证伪全部廉价杠杆后，唯一剩余方向是**改造预训练目标本身**。
> H5 oracle 定位天花板在"SSL 表征的跨试件可判别性"——本阶段测试能否用掩码目标
> 把表征推得更"缺陷回波物理"、更少"试件统计"。
> 方法学（P4a 教训）：**多 seed 才算数**，单 seed 结论一律不算。

---

## 1. 假设与协议

- **假设**：P1 SSL 掩码整波束（beam 轴）→ 编码器学"孔径/波束间统计"；
  缺陷回波是**深度（时间/声程）方向的局部指示**。改为掩码**深度块**，逼编码器用上下文
  重建被掩码的深度区域 → 学**局部回波形态**，该形态比试件统计更可跨试件迁移 →
  下游 LOOCV 应提升。
- **协议**：与 P1 完全同构（同架构 MAEEncoder/Decoder、同数据、同 40 epochs、同训练循环），
  只换掩码目标。下游用**冻结编码器 + 二分类头** LOOCV（同 P4a baseline 协议），
  **3 seed**（42/43/44）验证。
- **失败判据**：非PP4 逐折均值 ≥0.60 且 pooled ≥0.62，且跨 3 seed 稳定（P4a 的教训）。
- **对照**：P1 beam-mask 编码器下游多 seed baseline = **0.579±0.007**（逐折均值）/
  0.616±0.016（pooled）。

## 2. 部署

- 环境：`.venv_p2`，GPU2。`scripts/paut_p4b_ssl_depthmask.py`（新脚本，未改 P0–P3 代码）。
- 架构：`DepthMaskAE` 复用 `MAEEncoder/MAEDecoder`，掩码目标可配置
  （beam= P1 复现 / depth= 深度块 / both= 联合）。
- 预训练输出：`experiments/runs/ssl_ae_depth/encoder.pt`（depth）、
  `experiments/runs/ssl_ae_both/encoder.pt`（both）。

## 3. 结果

### 3.1 depth 模式（掩码 8 块中 2 块深度块）

| seed | 非PP4 逐折均值 | nonPP4 pooled | PP3 | PP5 | PP6 | PP7 |
|---|---|---|---|---|---|---|
| 42 | 0.506 | 0.605 | 0.479 | 0.488 | 0.482 | 0.575 |
| 43 | 0.521 | 0.613 | 0.480 | 0.503 | 0.522 | 0.578 |
| 44 | 0.511 | 0.612 | 0.474 | 0.494 | 0.499 | 0.576 |
| **depth 均值** | **0.513±0.008** | 0.610±0.004 | | | | |
| **P1 beam 对照** | **0.579±0.007** | 0.616±0.016 | | | | |

**结论：depth 模式显著负面**（0.513 vs 0.579，Δ=-0.066，远超 seed 噪声）。val_auc 与
baseline 相当（0.84-0.87），但 test 全面回落（PP6 0.48-0.52 vs 0.57-0.58, PP7 0.575 vs
0.68）。pooled 略高（0.610 vs 0.616，且在噪声内）且是试件级分量（P4a §3.1）。
**深度块重建使编码器学到的表征更试件化而非更可迁移**——与假设相反。

## 4. 诚实分析

### 4.1 三种掩码目标对比（下游冻结 + 二分类头, 3 seed 逐折均值）

| 预训练掩码目标 | 非PP4 逐折均值 | nonPP4 pooled | Δ vs beam | 结论 |
|---|---|---|---|---|
| **beam（P1 原版）** | **0.579±0.007** | 0.616±0.016 | - | 最强 |
| both（beam+depth） | 0.567±0.001 | 0.634–0.654 | -0.012 | ≈beam, 略低 |
| depth（深度块） | 0.513±0.008 | 0.610±0.004 | **-0.066** | 显著负面 |

- **depth 显著负面**：掩码深度块（2/8）编码器可用**邻深度/邻波束平滑上下文**重建，
  学到的是**深度方向平滑统计轮廓**（底面/几何回波深部位置）而非**缺陷局部形态**；
  val_auc 正常（0.84–0.87）但 test 全面回落（PP6/PP7 显著）→ 特征更试件化。
- **both ≈ beam（-0.012, 在 seed 噪声边缘）**：beam 主导，depth 组件不增反微减。
  物理直觉：PAUT 是**相控阵**，缺陷定位依赖**多波束相干联合（孔径合成）**，P1 的
  beam-mask 恰好逼出这一跨波束推理；depth-mask 绕开它，故无益。

### 4.2 P4b 假设结论

**"改掩码目标 → 更可迁移表征" 被证伪。** P1 beam-mask 已接近此数据上 SSL 表征的可达上限。
掩码目标从"跨波束推理"切换到"跨深度/局部形态"不提升、甚至损害跨试件可迁移性。

## 5. 结论

**P4b 为明确负面结果**，但极有价值：它把"预训练目标"这一最后廉价方向也钉死，
使 P4 证据图景完整——**提升不来自掩码目标、不来自有监督微调、不来自测试时适配、
不来自形态监督头、不来自融合、也不来自更多标签（+20% 无效）**。全部指向：

> **PAUT 跨试件位置级缺陷检测的 ~0.58–0.60（逐折均值）上限，是 5 试件数据集结构
> （缺陷率 0.5%–76% 与试件身份强耦合）下的表征级天花板，不是任何单一技术可破。**

**最可信归因（证据支撑）**：
1. 缺陷存在与试件缺陷率强耦合（PP4 0.5% ↔ PP6 76%）——LOOCV 把"判别缺陷"与"判别试件
   分布"混在一起，任何模型都被迫学试件统计捷径或牺牲判别力（DANN 失败、去试件均值
   反伤、SSL 特征线性不可分试件身份却携带试件级缺陷信号，均互证）。
2. 表征级：H5 oracle 同试件内 ~0.68（SSL 线性）/ 0.85（有监督头），跨试件 0.60；
   +20% test 折标签无效 → 不是标签量、不是模型容量、不是推理层。
3. 技术面：P0 增强/DANN/多视角、P1 两种掩码目标、P2/P3 图像+文本+CoT+LoRA、
   P4a 融合/微调/TTA/形态头——**零稳健突破**，且所有"看似提升"都被多 seed 证伪。

**可能翻盘的下一个目标（资源型，按预期收益排序）**：
1. **新试件数据**（最高收益）：更多试件（尤其缺陷率中段 20%–50%）可解耦"缺陷存在"
   与"试件缺陷率"，直接移除结构性天花板。需设备/合作方数据，超出本机算力范围。
2. **物理保真合成数据（方向6）**：仅当能生成与真实 .nde 几何（offset 80–85mm、
   71° focal law、TCG 增益、实际缺陷回波响应）一致的合成缺陷，才可能教"缺陷回波物理"
   而非"更多同分布样本"（H5-C 已证同分布加标签无效）。需 CIVA/射线模型仿真工具链。
3. **评估框架重定位**：位置级 LOOCV 在该数据上已达表征上限；实际部署中试件几何已知，
   per-coupon 校准/试件级缺陷率估计（筛查级）可能是更合适的落地框架。
4. **方向3 LLM 信号原生 bridge（受资源约束，预期低）**：H5 表明头部复杂度（LLM 作头）
   无法补不可分的表征；仅当新数据/合成数据改善表征后，该 bridge 才值得（届时 LLM 作为
   可解释"读波"头 + 回波归属标注输出，是北极星叙事）。
