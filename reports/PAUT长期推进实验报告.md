# PAUT 长期推进实验报告（P0-P2 三阶段汇总）

> 项目：大模型 + 焊缝无损检测（智能 NDT）｜ 方向：相控阵超声（PAUT）缺陷检测
> 日期：2026-08-07 ｜ 数据：5 试件 3000 位置，90 族 G0(71°, 49 波束) B-scan
> 评估：5 折留一试件交叉验证 (LOOCV)，PP3-PP7 轮流 test。**非PP4 AUC** 为可信指标
> （PP4 仅 3 正样本，AUC ±0.03 纯噪声）。

## 总览

| 阶段 | 技术 | 非PP4 AUC | 结论 |
|---|---|---|---|
| 基线 (P0) | SSF（谱-空-频） | 0.542 | 跨试件泛化差（远低于单点 PP7=0.626） |
| P0-② | 物理增强（beam_dropout 最优） | 0.557 (+0.019) | 负面：未稳健达 +0.03 |
| P0-③ | DANN 域对抗 | 0.510 (-0.028) | 负面：域对抗损害泛化 |
| P0-④ | 多视角 4 通道 | 0.526 (-0.012) | 负面：未提升 |
| P0-⑤ | temperature scaling | - (AUC 不变) | 校准小幅改善 (ECE 0.40→0.26) 但分布偏移仍大 |
| **P1** | **SSL 掩码自编码器预训练** | **0.572 (+0.030)** | **✓ 正面：超基线，首个有效技术** |
| P1 | MOMENT 冻结 | 0.470 | 负面：未迁移 |
| P1 | 异常检测（Weibull） | 0.473 | 弱 baseline |
| P2 | 多模态 LLM (Qwen3.6-27B) 零样本 | 0.593 (+0.051) | **✓ 正面：超 SSL，三阶段最优** |
| P2 | 多模态 LLM LoRA 微调 (PP7) | 0.587 (PP7) | ✓ 视觉端微调 +0.083 |

## P0：跨试件鲁棒评估 + 域适应 + 增强（负面）

LOOCV 揭示此前的单点 PP7=0.626 严重高估：裸 SSF LOOCV 非PP4 AUC 仅 0.542，encoder
0.512，RF 0.471。val_auc 0.86-0.93 但 test AUC 低，跨试件过拟合严重。

- **物理增强**（beam_dropout/time_shift/amp_jitter/gaussian_noise）：无配置稳健达 +0.03；
  beam_dropout 最优 (+0.019)，time_shift/all 反而退化。
- **DANN 域对抗**：-0.028。5 试件缺陷率差异极大（0.5%-76%），缺陷与域强耦合，域不变约束
  破坏缺陷判别力。
- **多视角 4 通道**（90/270 × G0/G1）：-0.012，未提升。
- **temperature scaling**：T≈19（过自信），ECE 0.401→0.261，缺陷率误差 0.296→0.249，但仍高。

**根本瓶颈**：试件级缺陷率分布偏移。详见 reports/PAUT_P0_LOOCV实验报告.md。

## P1：自监督预训练 + 异常检测（正面）

- **SSL 掩码自编码器**：在全部 11980 个无标注 B-scan（4 视角）上掩码波束重建预训练 40 epoch
  （loss 124→56）。下游冻结编码器 + 轻量头 LOOCV **非PP4 AUC=0.572**，超 ssl_scratch（同架构
  从零 0.542）+0.030，超 encoder（0.512）+0.060，超 SSF（0.542）+0.030。**首个有效提升跨试件
  泛化的技术**，验证「无标注 .nde 数据 + 域内 SSL 预训练」路线。
- **MOMENT 冻结**：0.470，未迁移（与 SAW 结论一致，通用 TS 大模型不迁移到焊缝 NDT）。
- **McKnight Weibull 异常检测**：raw 0.527 / Weibull 0.473 非PP4，偏弱（AE 含缺陷训练）。

详见 reports/PAUT_P1_SSL预训练实验报告.md。

## P2：多模态 LLM 缺陷检测（正面）

- **部署**：Qwen3.6-27B (Qwen3.5-VL, 视觉语言模型, 27.4B)。vLLM 0.26 需 CUDA13 但 driver 535
  仅支持 CUDA12.2（硬约束），回退 transformers 5.14 + torch cu126 直推，装 flash-linear-attention
  加速 linear attention（~0.3s/图）。
- **零样本 QA 似然打分**（全量 3000 位置）：B-scan 灰度图非PP4 AUC=**0.593** > 0.55 门槛，且
  **超过 SSL(0.572)/SSF(0.542)/encoder(0.512)**，为三阶段最优。频谱伪彩色 0.559（弱于灰度）。
  通用多模态 LLM 视觉先验可迁移到 PAUT，无需领域训练。
- **LoRA 微调视觉端**（LLM 冻结，2.98M 参数，PP7 单折）：AUC 0.504(零样本) -> **0.587** (+0.083)，
  少量标注（400 位置）即显著提升。

详见 reports/PAUT_P2_多模态LLM实验报告.md。

## 总结论与下一步

- **LOOCV 揭示真相**：单点评估（0.626）严重高估，跨试件泛化基线仅 0.54。
- **有监督增强/域适应无效**：P0 的物理增强、DANN、多视角全失败（非PP4 ≤0.557，多项退化）。
  根因是试件级缺陷率分布偏移（0.5%-76%），缺陷与域强耦合。
- **域内 SSL 有效**：P1 无标注域内 SSL 预训练把非PP4 AUC 提到 0.572（+0.030 vs 从零）。
  预训练须在 PAUT 域内（MOMENT 通用 TS 大模型未迁移，0.470）。
- **多模态 LLM 最优**：P2 通用多模态 LLM (Qwen3.6-27B) 零样本即达非PP4 0.593（三阶段最高，
  超 SSL），LoRA 微调视觉端进一步提升（PP7 0.504->0.587）。视觉先验 > 专用小模型从零训练。
- **PP4 退化**：仅 3 正样本使 AUC 评估脆弱（VLM 在 PP4 上 0.208 反向），凸显小缺陷样本下
  评估方法学问题，非PP4 AUC 是可信指标。
- **下一步**：(1) 多模态 LLM 完整 5 折 LOOCV + 更多标注微调；(2) SSL + 多模态 LLM 融合
  （SSL 数值表征 + VLM 视觉先验）；(3) 驱动升级后用 vLLM 重跑（更快推理/训练）；(4) 多 seed
  验证各方法稳健性；(5) SSL 仅在 clean 上训练 AE 改进异常检测。

## 三阶段技术路线对比

| 路线 | 代表 | 非PP4 AUC | 评价 |
|---|---|---|---|
| 有监督小模型从零 | SSF | 0.542 | 跨试件过拟合，增强/域适应无益 |
| 域内 SSL 预训练 | SSL 编码器 | 0.572 | 无标注数据有效，+0.030 |
| 通用多模态 LLM | Qwen3.6-27B 零样本 | **0.593** | 视觉先验最强，零样本即最优 |
| 多模态 LLM 微调 | LoRA 视觉端 | 0.587(PP7) | 少量标注进一步提升 |

**核心结论**：PAUT 跨试件缺陷检测中，**通用多模态 LLM 的视觉先验（零样本 0.593）>
域内 SSL 预训练（0.572）> 有监督小模型（0.542）**；有监督数据增强与域适应在此数据上无效。
