# PAUT P7 程序生成超声合成数据预训练实验报告

> 报告撰写: 2026-08-18
> 实验代号: **P7 (Synth-UT)**
> 阶段定位: **新方向启动** —— 当前 PAUT 真实数据 (5 试件 / 3000 位置) 太小,
> P0-P6 全杠杆证伪, 天花板在表征级 0.58。探索"程序生成物理保真超声 B-scan →
> 预训练编码器 → 真实下游"翻盘路径, 是 P4 报告点名但未走通的方向。

## 1. 动机与目标

### 1.1 上阶段结论
- PAUT 真实 5 试件数据, 主指标 (非PP4 逐折均值) 天花板 = **0.579±0.007** (P4a 规范头协议)
- P0-P6 共 7 个阶段, 7 类不同杠杆全部证伪 (增强/域对抗/SSL 掩码目标/物理注入/监督对比/TTT/样式不变 SSL)
- **关键诊断** (P4a/P6 三次验证): "缺陷强度与试件身份强耦合", 缺陷率 0.5%–76% 跨试件悬殊

### 1.2 翻盘路径 (P4 报告点名)
- 新试件数据解耦"缺陷存在"与"试件缺陷率"
- **CIVA 级物理保真合成数据教"缺陷回波物理"** ← 本工作

### 1.3 用户目标 (2026-08-18)
> "在当前的这个数据集, 只能是做小的。我们后续要做大模型的编码器训练。
> 你可以找一些数据集, 我们的目标是焊接的无损检测 + 大模型。
> 也有很多公开的仿真数据集可以用, 我们也可以用程序生成。
> 探索一下这个新方向, 也可以预训练时序大模型看看。"

### 1.4 本报告范围
- 第一步: 验证"程序生成"这条最易启动路径是否可行
- 不在本报告: CIVA 真仿真数据集 / 时序基础模型 / 真正的大模型规模 (这些由后续 P7b+ 处理)

## 2. 方法: Synth-UT 物理参数化超声 B-scan 合成器

### 2.1 合成器要素 (避免 P5 证伪的"假 2D 高斯峰")
`scripts/synth_ultrasound.py` 模拟 6 个真实超声传播要素:

| 要素 | 物理含义 | 实现 |
|---|---|---|
| 结构散斑噪声 | 晶粒散射 | 窄带带通噪声, 中心频率 f0, 深度方向衰减 |
| 缺陷回波 | 反射界面 | 高斯包络 × 正弦载波 (载波周期 6-14 样本) |
| 声束横向展宽 | 探头发散 | \|beam - 缺陷中心\| 高斯衰减, σ=beam_w (2-4.5 波束) |
| 走时几何 | 扇扫/线扫投影 | 缺陷深度随波束线性偏移 ±0.002/波束 |
| 底面回波 | 板厚界面 | 深度 0.95L 处强峰 (所有位置一致) |
| 试件级参数 | 增益/衰减/统计 | 12 试件各不同 (gain/atten/speckle/f0/bw/beam_w/def_amp/...) |

### 2.2 试件间"缺陷率-身份耦合"复现
- 真实 PAUT: PP3 0.57 / PP4 0.005 / PP5 0.44 / PP6 0.76 / PP7 0.14
- Synth-UT (12 试件, beta(1.5,2.0) 分布): 缺陷率 **0.04-0.74**, 含 2 个近零缺陷试件
- → 天然复现"缺陷率-试件耦合"挑战

### 2.3 与 P5 注入的根本差异
- **P5 (2D 高斯峰注入)**: 注入形状 = 标准 2D 高斯, 无散斑无衰减, 注入任务可学 0.998 但下游 0.545<0.579
- **P7 (Synth-UT 预训练)**: 预训练数据 = 完整物理 B-scan (散斑+回波+走时+底面), 编码器被迫学"回波物理"而非"高斯形状"

## 3. 实验设置

### 3.1 数据
- **合成数据**: 12 试件 × 1000 位置 = **12,000 样本** (N,49,512), 23.4 秒生成
- **真实 PAUT 数据** (下游评估): 5 试件 (PP3-PP7) × ~600 位置 = 3,000 样本 (单视角)

### 3.2 预训练 (P1 base 风格, MaskedAE)
- 模型: `MAEEncoder` (CNN 3 层, 128 维) + 30% 掩码波束重建
- epochs=40, batch=256, lr=1e-3 (同 P6 --variant base)
- 数据: 合成 12k (或 合成+真实 16k 联合, 当 `--mix-real`)

### 3.3 下游评估 (真实 PAUT 5 折 LOOCV, 规范头协议)
- 冻结编码器 + 分类头 lr=1e-3/80ep/batch=128, val AUC 早停 patience=20
- 5 折 LOOCV by coupon, 报 **非PP4 4 折均值** (P4a 同口径)

### 3.4 对照基线 (P4a)
- **P4a 真实预训练非PP4** = **0.579±0.007** (天花板)
- P6 真实预训练 batch=128 = 0.556
- 跨试件缺陷率耦合 → 任何使"缺陷强度-试件身份"对齐的预训练都可能负向

## 4. 结果

### 4.1 P7a 主结果 (纯合成预训练 → 真实 LOOCV, 2026-08-18, seed=42)

| 折 | n_test | def_rate | val AUC | **test AUC** |
|---|---|---|---|---|
| PP3 | 601 | 0.574 | 0.833 | 0.4630 |
| PP4 | 601 | 0.005 | 0.754 | 0.3177 |
| PP5 | 596 | 0.438 | 0.763 | 0.5529 |
| PP6 | 601 | 0.764 | 0.687 | 0.4164 |
| PP7 | 601 | 0.138 | 0.757 | 0.6162 |

**主指标 (非PP4 4 折均值, P4a 同口径): 0.5121 ± 0.0776** (vs P4a 0.579±0.007, **-0.067 显著负向**)
全 5 折均值: 0.4732 ± 0.1042

### 4.2 关键诊断

1. **val-test gap 巨大** (val 0.83 → test 0.46): 编码器在训练试件上"学得很好", 跨试件泛化失效
2. **缺陷率越低 test 越差** (PP7 0.14→0.62 vs PP4 0.005→0.32, 但 PP3 0.57→0.46 反常): 编码器**学到合成 cfg 风格作为判别捷径**而非缺陷回波物理, 在真实试件上无 cfg 信息可用
3. **sim2real gap 复现**: 精确对应 agent 报告 [arXiv:2306.01469] 的"纯半解析仿真 F1 仅 0.394"档; 我跑到 0.51 介于"纯仿真失败 0.394"和"GAN 增强 0.629-0.843"之间
4. **variance 暴增** (0.078 vs P4a 0.007, 11 倍): 不稳定的负向迁移, 比"全杠杆证伪"更不健康

### 4.3 失败原因分析

- **直接原因**: Synth-UT 每个试件由独立 cfg 生成 (gain/atten/speckle/f0/...), 编码器在 30% 掩码重建预训练中学到"试件 cfg 风格"作为快速捷径 (val 0.83 验证); 测试时真实试件无 cfg 信息, 编码器失效
- **深层原因**: 程序生成天然强化了"缺陷强度-试件身份耦合"——每个 cfg 是一组独立的物理参数, 编码器被迫把 cfg 与缺陷混在一起
- **可解决的路径**: 加 GAN/工艺噪声层 [2306.01469 证据: 纯仿真 F1 0.394 → GAN 增强 0.629-0.843, +0.235 到 +0.449] / 改用真仿真 (k-Wave, CIVA) / 联合预训练 (StorSeismic 模板)

### 4.4 结论

> **P7a 证伪: 程序生成物理保真 Synth-UT 数据单独预训练, 在真实 PAUT LOOCV 上显著负向 (-0.067)**。
> 但**这不是"程序生成路径失败", 而是"缺少 sim2real 弥合层"**。这与 agent 调研报告独立预言一致。

**下一步必跑 P7b (StorSeismic 模板: 合成+真实联合预训练)** —— 如果 P7b 仍 ≤ 0.579, 则程序生成路径基本无效; 如果 P7b > 0.579, 则是"合成数据补充真实数据"的首次正证据。

### 4.5 P7b 结果 (合成+真实联合预训练, StorSeismic 模板, 2026-08-18 seed=42)

| 折 | n_test | def_rate | val AUC | **test AUC** | P7a 对照 |
|---|---|---|---|---|---|
| PP3 | 601 | 0.574 | 0.814 | 0.4913 | 0.4630 |
| PP4 | 601 | 0.005 | 0.609 | 0.6505 | 0.3177 |
| PP5 | 596 | 0.438 | 0.664 | 0.5102 | 0.5529 |
| PP6 | 601 | 0.764 | 0.606 | 0.5866 | 0.4164 |
| PP7 | 601 | 0.138 | 0.701 | 0.6493 | 0.6162 |

**主指标 (非PP4 4 折均值): 0.5594 ± 0.0630** (vs P7a 0.512, **+0.047 显著改善**; vs P4a 0.579, **-0.020 仍负**)
全 5 折均值: 0.5776 ± 0.0671 (vs P4a 0.579, **-0.001 几乎一致**)

### 4.6 P7b 关键诊断

1. **StorSeismic 模板有效**: 联合预训练 (12k 合成 + 3k 真实) 把非PP4 从 0.512 提到 0.559 (+0.047, +9.2%) —— 真实数据修正了合成偏置
2. **PP4 (近零缺陷) 显著恢复**: 0.32 → 0.65 (+0.33) —— 真实数据教会编码器在无 cfg 信息下也能判别
3. **方差大幅改善** (0.063 vs P7a 0.078, -19%) 但仍 > P4a 9 倍 —— 联合预训练稳定了训练, 但合成主导 (12/15 = 80%) 仍是瓶颈
4. **仍未翻盘 0.579**: 单靠"程序生成 + 联合预训练"路径在 12k 规模上不够, 需更大规模或外部数据

### 4.7 决策树

- ✅ **P7a → P7b 路径有效**: 联合预训练是正确范式 (StorSeismic)
- ❌ **未翻盘 0.579**: 12k 合成 + 3k 真实 = 80/20 合成主导, 需扩大试件多样性 / 试件比例 / 外部数据
- 🔄 **P7c (跑中)**: mix 100k 合成 (50 试件) + 3k 真实, 验证"试件多样性"是否翻盘
- 📋 **后续候选**: P7d 工艺噪声 (2306.01469 教训) / P7e UGW-3Mat-2SN 外部超声数据 (43.5GB) / P7f SimNDT 真仿真

## 5. 与新方向 (大模型 + 时序基础模型) 的连接

本实验只是新方向的"第一块砖"。基于 2026-08-18 调研 agent 报告 (时序大模型 + 超声/地震基础模型 + sim2real), 后续路径与证据如下:

### 5.1 调研核心发现 (与本项目自洽)

- **NCS-Model (arXiv:2603.23211) + 胎儿超声 (MICCAI'25, arXiv:2506.19552) 独立证据**: 自然图像预训练不迁移到超声/地震域, **域内自监督预训练胜过放大全局基线** → 项目 P4-P6 的"域内 SSL"路线方向正确, 但当前小数据 5 试件撑不起"大尺度+域内"的范式。
- **USFM (arXiv:2401.00153) 频域掩码 (200 万超声图)**: 在物理信号上是最被验证的 SSL 目标, 跨 10 基准 SOTA → 项目当前 P1/P4b/P6 都是波束域/空间域掩码, 频域掩码是新的目标方向。
- **StorSeismic (arXiv:2205.00222)**: "合成+真实混合, 自监督预训练编码器 → 现场数据推断" 的直接模板 → 与本报告的 P7a→P7b 路线对应。
- **sim2real 关键教训 (arXiv:2306.01469)**: 纯仿真数据训练 F1 仅 0.394, **GAN 风格噪声增强后 0.629-0.843** → 程序生成的 Synth-UT 当前缺"工艺噪声层", P7c 需补; 否则合成预训练可能负向迁移。

### 5.2 后续实验路径 (按优先级)

| 阶段 | 名称 | 内容 | 关键依赖 | 预期 |
|---|---|---|---|---|
| **P7a** | 纯合成预训练基线 | Synth-UT 12k → 真实 LOOCV (本报告, 跑中) | 当前脚本 | 验证迁移基线 |
| **P7b** | 混合预训练 | 合成 12k + 真实 3k 联合预训练 → 真实 LOOCV (StorSeismic 模板) | P7a ≥ 0.55 | 验证"合成+真实"互补 |
| **P7c** | 工艺噪声增强 | Synth-UT + GAN 风格噪声 (2306.01469 教训) | P7b 跑通 | 弥合 sim2real gap |
| **P7d** | 频域掩码目标 | USFM 式 2D FFT 频带掩码替换通用 MAE | P7b ≥ 0.56 | 目标创新 |
| **P7e** | Moirai 编码器 | 任意变量数 (49 波束) patch 编码器替换 MAEEncoder | P7d 跑通 | 跨域大模型迁移 |
| **P7f** | 大编码器规模 | d_model=512/1024 + 多层, 看程序生成数据能否喂出更大模型 | P7e 跑通 | 验证 "规模化"翻盘路径 |
| **P7g** | k-Wave 真仿真 | 替换程序生成为 k-Wave 物理仿真 (5 试件 5 类别焊缝缺陷) | P7c 跑通 | 物理保真度升级 |
| **P7h** | 公开数据集 | PENELOPE 其他工作包 / CIVA / 超声 NDT benchmark | 调研 #1 agent | 引入外部数据 |

### 5.3 关键借鉴清单 (agent 报告已核实)

- **时序基础模型**: Moirai ([Salesforce/moirai-1.1-R-large](https://huggingface.co/Salesforce/moirai-1.1-R-large), 0.3B 权重, LOTSA 27B 观测, cc-by-nc, [uni2ts](https://github.com/SalesforceAIResearch/uni2ts)) 任意变量数 → B-scan 49 波束最契合; patch 4-8 保窄回波峰 (patch=32 必丢)
- **波形级 SSL**: SeisLM (arXiv:2410.15765) → 波形级 BERT 式对比预训练, [liutlin0121/seisLM]
- **医学超声 FM**: USFM (arXiv:2401.00153, 200万图, 频域掩码), USF-MAE (arXiv:2510.22990, 37万图), UltraSam (arXiv:2411.16222), OpenUS (arXiv:2511.11510, Mamba+对比)
- **地震/合成迁移**: StorSeismic, DeFault, GSFM (扩散式 + 合成 → 现场微调)
- **B-scan 长度对齐**: TimesFM/MOMENT/Chronos 上下文均 512 → 恰好对齐 B-scan 512 深度
- **⚠ 未核实**: GETS 2.0 / SeisFM / WavEnSeis 在 arXiv 上检索不到, 慎用

## 6. 复现命令

```bash
# Step 1: 程序生成 12 试件 × 1000 位置合成数据 (~24s)
python scripts/synth_ultrasound.py --n-coupons 12 --n-pos-per-coupon 1000 --seed 42

# Step 2: 纯合成预训练 → 真实 LOOCV (核心新方向探针)
python scripts/paut_p7_synth_to_real.py --pretrain-epochs 40 --seed 42

# Step 3: 合成+真实联合预训练 → 真实 LOOCV (下一步对照)
python scripts/paut_p7_synth_to_real.py --mix-real --pretrain-epochs 60 --seed 42
```
