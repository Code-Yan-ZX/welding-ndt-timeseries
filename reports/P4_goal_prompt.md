## 远景使命（北极星）

项目的终极目标是**智能无损检测**：让大模型像资深超声检验员一样，**直接读懂相控阵超声（PAUT）信号**——识别缺陷、鉴别"缺陷回波 vs 几何回波（底面/角/模式转换）"、解释"为什么"，并且在**跨试件 / 跨工况**下稳健泛化。当前聚焦在 PAUT 焊缝缺陷检测上，但思路要能外推到其它 NDT 模态。

P0–P3 四阶段已经测出了一条路的边界（见下）。你的任务不是在这条路的边界内再修修补补，而是**打破它**——让模型真正理解"波场"，而不是把超声当成自然图片。

## 已确认事实（约束，不要重做）

- 工作目录：`/home/yzx/doct/welding-ndt-timeseries`（git 仓库，分支 main）。
- **评测口径（与历史同口径，不可变）**：5 折留一试件 LOOCV（PP3–PP7 轮流 test），**非 PP4 AUC 为主指标**。PP4 经官方 UT 报告证实是近零缺陷试件（仅 1 个可接受气孔、3 正样本），其单折 AUC 是纯噪声，不纳入均值；但每折仍要单独报告。
- 历史结果（非 PP4 AUC）：
  - P0 小模型（SSF 谱-空-频）0.542；物理增强 / DANN / 多视角全失败。
  - P1 域内 SSL 掩码自编码器 0.572（+0.030，首个有效技术）。
  - P2 通用 VLM（Qwen3.6-27B）零样本看 B-scan 图 **0.593**（三阶段最优）。
  - P3 物理条件化 prompt 0.512 / CoT 差分诊断 0.508 / LoRA 5 折均值 0.510 —— **全部低于裸图 bare 复现 0.600**。结论：**图像路线的天花板 ~0.59–0.60；瓶颈是感知（VLM 把 B-scan 当普通图片，读不懂波场），不是推理。**
- **已耗尽、不要重做**的路线：
  - 图像栅格化 + prompt / 物理条件文本 / CoT / LoRA 微调（P3 已证伪）。
  - 通用 VLM 看渲染图（P2 已触顶，~0.59）。
  - 预训练时序基础模型冻结迁移（P1 证伪，MOMENT 0.470）。
- **数据稀缺是所有人卡在 ~0.59 的根因之一**：仅 5 块试件 / 1798 个有效位置，缺陷率 0.5%–76% 强分布偏移，val/test 失配，跨试件泛化难。

## 任务：你自己定目标

下面这些是**起点提示**，不是方案——被列出来只是因为调研里已被标记为"值得看"。你完全可以、也应当去找它们之外的创新点：

- **合成数据**：波动方程 / 射线模型仿真生成物理有效的合成缺陷数据，解决数据稀缺（可支撑任何方向）。
- 其它任何你认为能打破"感知 / 数据"瓶颈的路线：新编码器设计、新的预训练目标、对比学习、信号域增强、多视角利用、缺陷类型辅助任务、把"解释"做成可验证的输出（如给回波打归属标注）……

要求：
