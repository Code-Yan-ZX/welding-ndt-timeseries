## 1. 文献调研（arXiv，2026-08-14 检索）

检索角度：超声/NDT SSL、跨域(跨试件)表征泛化、MAE 掩码/重建目标创新、对比/去相关 SSL。
代表性论文与"为什么适合/不适合我们的 beam-mask MAE 基线"：

### 1.1 超声专用 SSL
| 论文 | 核心方法 | 与本项目关系 |
|---|---|---|
| **USF-MAE** (2510.22990, 2025) | 37 万张超声图大规模 MAE 预训练 | 验证 MAE 路线；无数据可搬，但说明"域内 MAE 预训练"是超声主流 |

### 1.4 对比/去相关 SSL
| 论文 | 核心方法 | 与本项目关系 |
|---|---|---|
| **Barlow Twins / VICReg / Whitening-MSE** (2021-2022) | 去相关/冗余消除，非对比 | 备选：与已败 SupCon（正负样本对比）机理不同，但需新的增广对定义 |
| **Spectral Contrastive** (2021) | 谱对比损失 | 备选 |
| **SAM** (2021) | 锐度感知最小化，平坦极小 | 备选：优化层面创新，成本 2× |

### 1.5 文献调研结论
最有希望的方向是 **"在 SSL 预训练阶段教编码器对试件样式不变"**：BSS（最简）与
DiMAE（重建式域不变）都直接针对"试件身份耦合缺陷率"这一核心矛盾，且机理与已证伪的
DANN（对抗式，会把缺陷信号一起洗掉）和 P4a"去试件均值"（特征层一刀切）不同。
其次是把重建目标从"原始散斑"改为"平滑/去模糊版"（Deblurring MAE / PixMIM），
避免编码器把容量花在拟合不可迁移的试件噪声上。

## 2. 方法（P6 变体，均只改预训练，下游同协议）

| 变体 | 预训练改动 | 论文依据 | 预期机制 |
|---|---|---|---|
| `base` | P1 复现（掩码 30% 波束 + 高斯噪声 + Huber 重建） | P1/P4a | 同 env 对照（应 ≈0.571 seed42） |
| `bss` | 每批 2D FFT，各样本幅值谱替换为该批平均幅值（保留相位） | BSS 2303.06088 | 去试件增益/噪声风格 → 依赖相位（回波位置结构） |
| `deblur` | 重建目标 = 高斯模糊原图（核 9, σ=2） | Deblurring MAE 2306.08249 / PixMIM 2303.02416 | 避免拟合散斑噪声，专注回波结构 |
| `dimae` | 内容保持风格混合 + 逐试件解码器，跨试件重建 | DiMAE 2205.04771 | 重建式域不变，风格由解码器吸收，编码器保内容 |
| `multidec` | 仅逐试件解码器，无风格混合（隔离风格混合贡献） | DiMAE 消融 | 对照 |

- 预训练：同 P1（40 epoch, AdamW lr=1e-3, cosine warmup, grad-clip 1.0, batch 128）。
- 下游：**冻结编码器 + 分类头（规范头 lr=1e-3/80ep）**，5 折 LOOCV，非PP4 逐折均值 + pooled。
- 成功判据：非PP4 逐折均值 ≥0.60 且跨 3 seed 稳定（P4a 教训）；对照 baseline 0.579±0.007
  （seed42=0.571 / s43=0.582 / s44=0.583）。

## 3. 结果

> ⚠ **方法学发现（重要）**：P6 预训练用 batch=128（P1 原用 batch=256），下游头同为
> batch=128。同 seed 下 **P6 base 非PP4 逐折均值 = 0.556**，比 P1 规范基线（0.571）
> 低 0.015 —— **预训练 batch 大小是显著超参**（0.556 vs 0.571，仅 batch 256→128）。
> 因此：① P6 各变体的创新贡献须与**同环境 base（0.556）**比较；② 若有变体显著为正
> （Δ≥+0.02），需以 batch=256 重训对齐规范口径（0.579±0.007）后才有资格谈"超 SOTA"。

## 4. 结论（seed 42 单 seed，exploratory negative evidence）

**4 个文献驱动的 SSL 预训练创新全部未突破基线，且随"去试件样式"强度增大而变差：**

| 变体 | 机制 | 非PP4 | Δ vs base | PP7 Δ |
|---|---|---|---|---|
| bss | 傅里叶幅值标准化（去增益/噪声样式） | 0.554 | -0.002 | **-0.062** |
| deblur | 模糊重建目标（去散斑噪声） | 0.551 | -0.005 | -0.031 |
| dimae | 跨试件风格混合 + 逐试件解码器（重建式域不变） | 0.521 | -0.035 | **-0.147** |
| multidec | 仅逐试件解码器 | 0.517 | -0.039 | **-0.152** |

**反复出现的失败模式**：所有变体在中缺陷率折（PP5）小幅获益（+0.01~+0.06），但在
稀疏缺陷折 **PP7 系统性崩塌**（-0.03~-0.15）。机制归因清晰：**任何试图移除"试件样式/
试件统计"的预训练改动，都同时移除了与试件身份耦合的缺陷强度信息**（P4a"试件级特征
携带缺陷信号"的归因被 P6 三个独立机制再次验证）——PP7 缺陷率仅 12%，其缺陷信号
高度依赖试件级幅值/统计，一旦被标准化/模糊/解码器吸收，判别力即崩。

**对照结论**：DiMAE 式的"重建式域不变"虽理论上是 DANN（对抗式）的合理替代，但在这
个数据上同样失败（甚至更差）。这与 P0 DANN 失败、P4a 去试件均值失败、P5 合成注入
失败共同构成完整证据链：**PAUT 跨试件位置级缺陷检测的天花板是数据结构（缺陷率与试件
身份强耦合）决定的，不是预训练目标/表征不变性可破的。**

**对"超过 SOTA 0.579"的诚实回答：P6 未达成。** 且由于 P6 base（batch 128）已比规范
基线（batch 256）低 0.015，即使个别变体在 batch 128 下略升（如 bss PP5），也不足以
在 batch 256 规范口径下超过 0.579。**翻盘仍需资源型路径**（新试件数据解耦缺陷率与试件、
或 CIVA 级物理保真合成教"缺陷回波物理"），与 P4b 结论一致。

## 5. 多 seed 说明
P6 目前为 seed 42 单 seed。按 P4a 教训，单 seed 不构成"稳健超基线"证据；但本阶段全部
变体**相对 base 均为 ≤0 或负**，且负面幅度（dimae/multidec -0.035/-0.039）远超 seed
噪声（~±0.008），方向已明确，无需多 seed 即可定论为负面。bss/deblur 的 -0.002/-0.005
在 seed 噪声内，按中性处理，多 seed 收益低（PP7 崩塌模式已足够说明问题）。

**bss 小结（seed42, 单 seed 仅供参考）**：非PP4 0.554 ≈ base 0.556（净 0）。机制上 PP5（中缺陷率）
**+0.058** 但 PP7（稀疏缺陷）**-0.062** —— BSS 把傅里叶幅值标准化，同时洗掉了稀疏缺陷试件的部分
缺陷强度信息（与 P4a"试件级特征携带缺陷信号"归因一致），中缺陷率折受益。净效应≈0，未达成功门槛，
需多 seed 才能定论（当前先按中性处理）。

## 6. 状态汇总（M0-1.5 修正）

- **状态**：seed42 单 seed 结果完整，**exploratory negative evidence**；不称"完整证伪"。
- **相对结论**：4 个文献创新相对同 env base（0.556）均 ≤0 或显著负，方向明确为负面；
  bss/deblur 在 seed 噪声内按中性处理。
- **遗留**：多 seed 未跑（按负面幅度远超 seed 噪声判断，收益低）；预训练 batch 256→128
  使基线 0.571→0.556（batch 是显著超参），P6 各变体须与同 env base 比较。
