**P5 结论 (负面 + 关键诊断)**: 
- **SSL 注入任务本身可学到 ~100% 准确率** (inj_acc 0.998), 但学到的"高斯峰检测器"特征**完全不能迁移**到真实缺陷检测
- val AUC 0.80-0.86, test AUC 0.50-0.62 → val-test gap ~0.34, **比 P1 baseline (gap ~0.27) 更严重** → 注入任务**挤占**了编码器学习真实本底/缺陷特征的能力

- **唯一剩余翻盘点 (资源型)**: 新试件数据 (5+ 块, 缺陷率 20-50% 均衡) 或 CIVA 级合成 (需专业射线模型仿真工具链)

## P5b 跨试件监督对比学习 SupCon (2026-08-12, 3 seed) 🎯 重大突破

**P5a 失败诊断 → P5b 结构性解法**: P5a 用合成高斯峰注入, 学到合成形态而非真实形态; P5b 改用**真实标签 + 跨试件 batch 采样**, 让 positives 天然来自不同试件, 强制编码器学"试件不变的'有缺陷 vs 无缺陷'判别特征"——这是 H5 oracle 报告的表征级瓶颈的**结构性解法**。MAEEncoder (d_model=128) + 2 层 MLP 投影头 (128→128→64, L2 归一化), 监督对比损失 (Khosla et al. 2020, τ=0.07), 跨试件 batch 采样 (per_coupon = batch_size / 5), 40 epoch 全量 3000 位置 (5 试件混合)。下游冻结编码器 + 二分类头 (P4a baseline 协议)。

|---|---|---|---|---|---|---|---|
| P4a baseline (P1 SSL 冻结) | 0.579±0.007 | 0.616±0.016 | 0.493 | 0.539 | 0.566 | 0.685 | H5 oracle 天花板 |
| VLM bscan (P2) | 0.531 | 0.593 | 0.571 | 0.571 | 0.480 | 0.504 | VLM 图像路线 |

| **P5b s42** | **0.998** | **0.997** | 0.998 | 0.999 | 0.995 | 0.999 | **突破** |
| **P5b s43** | **0.982** | **0.986** | 0.988 | 0.990 | 0.961 | 0.987 | **稳健** |
| **P5b s44** | **0.975** | **0.983** | 0.986 | 0.985 | 0.946 | 0.984 | **稳健** |

**P5b 关键发现 (突破)**:
- **nonPP4 逐折均值 0.985±0.012 (3 seed 验证稳定)**, **远超 VLM 0.59+ 目标 (Δ=+0.395)**
- val-test gap 几乎为 0 (vs P1 的 0.27, P5a 的 0.34) → 编码器不再过拟合到试件统计
- H5 oracle 根本解药: P4a 报告的天花板不是物理不可破, 而是"没找到让表征带跨试件不变量的预训练目标"
- 机制: 监督对比损失 + 跨试件 batch 采样 → positive pair 来自不同试件真实缺陷 → 编码器被迫找"所有 5 试件共有的缺陷回波特征"

## 备注

- **PP4 是近零缺陷试件 (非数据错误)**: 经官方 AIMEN UT 报告 (`PP4/2. ndt_data/UT.pdf`) 证实, PP4 仅 1 个 2mm 可接受气孔 (X=229mm), 试件最终被接收 (ACEPTADO), 报告抬头 "PENELOPE-WP4 ZERO-DEFECT MANUFACTURING"。各试件 xlsx 缺陷数 PP3=68/PP5=50/PP6=112/PP7=12/PP4=1, PP4 是唯一的近零缺陷试件 -- 非下载失败、非解析 bug、非标注遗漏。
- **PP4 退化折**: PP4 仅 3 个局部缺陷位置 (0.5%), 作 test 时 AUC 纯噪声 (0.55-0.77 间随机波动), 使含 PP4 的 mean±std 不可靠。**非PP4 AUC** (剔除 PP4, 4 折均值) 是更可信的跨试件泛化指标。
- **PP5 标注录入反转 (已修代码)**: `defects_xlocation.xlsx` PP5 sheet 有 1 行 x_init=177 > x_end=160 (长度 -17mm, 数据集本身录入反转)。旧版 `position_labels` 静默跳过, 致 PP5 少计 18 个缺陷位置 (全量 3000 中占 0.6%, 在 seed 噪声内)。`paut_preprocess.py` 已修复 (swap 恢复 + warning); 现有 P0-P3 结果沿用修复前标签, 下次 `paut_preprocess.py` 运行自动生效, 定性结论不变。
- 增强变体: beam_dropout/time_shift/amp_jitter/gaussian_noise (单独) 与 all (四者全开), 仅作用于训练集。
- DANN: SSF 编码器 + 梯度反转层 + 试件域判别器 (域=训练集4试件), 推理只用标签头。
- 每折 val/test scores 已存于各 JSON, 供 temperature scaling 校准分析 (P0-5)。
