# 焊接 NDT + 大模型:后续研究 goal 规划

> 由子 agent 阅读 `docs/papers/` 8 篇论文 + 项目报告/结果后规划,2026-08-06。

## 一、论文要点速览

| # | 论文 | 核心方法 | 与本项目 PAUT 的可借鉴点 |
|---|------|---------|------------------------|
| 01 | Alliance (TPAMI 2025) | 谱-空-频三分支并行编码 + 跨模态融合 | **已实现**(SSF 0.626)。可深化:加自监督预训练 + 跨维度注意力 |
| 02 | Zhang PAUT U-Net (NDT&E 2024) | U-Net 分割 PAUT B-scan,CE+Dice 处理类不平衡 | **直接基线**:从位置级二分类迈向 B-scan 像素级分割 |
| 03 | Jeon SSL (Ultrasonics 2025) | 领域知识合成缺陷 + 去噪自编码器,重构误差=异常 | PAUT 标注稀缺,可用合成缺陷 + DAE 做少监督检测 |
| 04 | McKnight 3-DUSSS (2024) | 仅用无缺陷数据训练,1D CNN 预测 Weibull 分布,486K 参数达 100% 检测率 | 纯无监督异常检测 baseline;Weibull 建模 PAUT 包络分布 |
| 05 | Chen GAN-Diffusion (Measurement 2026) | StyleGAN2+DDPM 条件生成 B-scan 缺陷图像 | 小样本增强;但应先与简单物理增强对比 |

| 07 | Zhou WRT-SAM (2025) | SAM + 频率提示生成器 + Adapter,焊缝 RT 分割 AUC 0.9746 | 频率提示生成器可迁移到 PAUT;Adapter 轻量微调 |
| 08 | Wang VLT (2026) | Time-MoE + 频谱视觉学习器 + 语言对齐训练器,频谱作"视觉桥梁" | 将 A-scan 频谱转伪彩色图喂视觉 LLM;梯度对齐解决多模态训练冲突;少样本迁移 |

## 二、现状诊断:四个核心瓶颈

1. **跨试件泛化难(首要)**:train(PP3/4/5)->test(PP7)焊接参数域漂移;val(PP6 76%缺陷)vs test(PP7 14%缺陷)率失配,阈值不可迁移,AUC 0.5–0.63 均不高。且仅 1 个 test 试件,评估方差大。
2. **数据规模小**:PAUT 仅 3000 位置(1798 训练),encoder 方差 ±0.12(seed43 崩溃至 0.36)。
3. **标注粗糙**:只有轴向 x 位置 + 缺陷类型代码,无深度 z,无波束级标注。
4. **冻结基础模型不迁移**:MOMENT 在 PAUT(0.459)和 SAW(0.489)均失败。

## 三、候选 goal 方向

### 方向 A:自监督 PAUT 预训练 + 异常检测(解决瓶颈 2+4)
- **动机**:MOMENT 冻结失败说明通用时序基础模型不迁移;应在域内无标注 PAUT 数据上自监督预训练。
- **关联论文**:Jeon(03 合成缺陷+DAE)、McKnight(04 Weibull 异常)、Alliance(01 SSL 预训练)。
- **设计**:解析全部 11 个 .nde 的全 DataGroup(90/270 族 × G0/G1,远超 3000 位置)-> 掩码重建 / Jeon 式 DAE 预训练 -> 下游:SSL 编码器替换 SSF 的 ConvBranch;或 McKnight 式纯异常检测(无标注 baseline)。
- **可行性**:高。数据已在本地,模型轻量(486K–0.8M),单卡足够。
- **风险**:3000 位置 SSL 仍偏小;合成缺陷可能不匹配真实形态;异常检测可能误判参数漂移。

### 方向 B:跨试件鲁棒评估 + 域适应 + 数据增强(解决瓶颈 1)
- **动机**:当前评估仅 1 个 test 试件,val/test 失配,AUC 可能是偶然。跨试件域漂移是明确首要瓶颈。
- **关联论文**:Li(06 域不变特征选择)、Chen(05 增强)、Alliance(01 跨任务迁移)。
- **设计**:① 留一试件交叉验证 LOOCV(5 折 mean±std 替代单点);② 物理增强(beam dropout/时移/幅度抖动/噪声)先于生成模型;③ DANN 域对抗;④ 多视角(270 族 + G1 47° 拼接,当前闲置);⑤ 缺陷率校准(温度标定)。
- **可行性**:最高。LOOCV 改划分脚本;增强几行代码;几小时内出结果。
- **风险**:5 试件 LOOCV 仍有方差;DANN 在仅 5 域上可能不稳。

### 方向 C:多模态 LLM 缺陷检测(发挥 Qwen3.6-27B,对接 LLM+NDT 愿景)
- **动机**:项目核心是"大模型+NDT",Qwen3.6-27B 已就位(多模态)。VLT 验证了"频谱作视觉桥梁"。
- **关联论文**:VLT(08 频谱伪彩色图)、WRT-SAM(07 频率提示+Adapter)、ITFormer(本项目基线桥接)。
- **设计**:输入表示三选一--B-scan 灰度图 / VLT 式频谱伪彩色图 / ITFormer 式 token 桥接;QA 式似然打分(复用 GMAW 范式);阶段 1 零/少样本验证迁移,阶段 2 LoRA/Adapter 微调。
- **可行性**:中。27B 部署需 2 卡(有 3 张);3000 样本微调偏小;零样本可能如 MOMENT 般失败。
- **风险**:多模态 LLM 可能同样不迁移;图像化丢数值精度;推理成本高 2–3 个数量级。

### 方向 D:弱监督/自监督缺陷分割定位(突破位置级)
- **动机**:位置级二分类浪费了 B-scan 的(波束×深度)二维结构。分割能提供缺陷大小+深度。
- **关联论文**:Zhang(02 U-Net 分割)、WRT-SAM(07 SAM 频率提示)、McKnight(04 自监督分割)、Jeon(03 重构定位)。
- **设计**:弱监督(CAM/注意力生成伪掩码迭代训 U-Net)/ 自监督(McKnight Weibull 偏离)/ SAM-Adapter;评估靠下游检测 AUC 间接衡量(无分割 GT)。
- **可行性**:中低。无分割/深度 ground truth,无法定量验证分割质量。
- **风险**:无 GT 是硬伤;依赖更好的分类基线(需 B+A 先提升)。

## 四、推荐优先级

| 优先级 | 方向 | 理由 |
|--------|------|------|
| **P0(立即)** | **B:跨试件鲁棒评估 + 域适应 + 增强** | 解决"评估不可靠"元问题(0.626 可能是单点偶然);直接攻首要瓶颈;可行性最高(几小时出结果);多视角数据闲置可用 |
| **P1(紧随)** | **A:自监督 PAUT 预训练 + 异常检测** | 对 MOMENT 失败的最有力回应(域内自建);利用闲置全 DataGroup 数据;方法论清晰可行;需在 B 的可信评估下衡量 |
| **P2(中期)** | **C:多模态 LLM 缺陷检测** | 最契合 LLM+NDT 愿景,Qwen3.6-27B 已就位;但风险最高,应在 B+A 建立可信基线后试;零样本阶段快速验证止损 |
| **P3(远期)** | **D:弱监督分割定位** | NDT 应用价值高(定位+定量),但无分割 GT 是硬伤;依赖更好基线和可能的额外标注 |

**排序逻辑**:B 是地基(可信评估),A 是核心模型突破(域内 SSL),C 是愿景探索(多模态 LLM),D 是应用深化(分割定位)。

## 五、首要 goal(P0)定义--可直接作为 /goal 输入

> **PAUT 跨试件鲁棒评估框架 + 域适应与数据增强基线**:解决当前 PAUT 缺陷检测评估不可靠(单 test 试件 PP7、val/test 缺陷率失配 76% vs 14%)和跨试件域漂移问题。① 建立留一试件交叉验证(LOOCV)框架,5 折 AUC mean±std 替代单点评估,对 SSF/encoder/classic RF 重跑建立可信基线;② 实现 PAUT 物理增强(beam dropout/时移/幅度抖动/噪声)并消融;③ 在 SSF 上加 DANN 域对抗学习试件不变特征;④ 解析 270 族 + Group1(47°)作多视角输入通道;⑤ 缺陷率校准改善阈值迁移。成功标准:LOOCV 框架上线;SSF+增强+DANN 的 LOOCV AUC 较裸 SSF 提升 ≥0.03。约束:不引入新标注,单卡可运行,8 小时内完成,报告入 reports/,严正兴名义提交无 AI 署名。
